API Template using NodeJs

This is a free Node.js API template to help you start your server with a modern architecture and MySQL integration.
Getting Started
Clone this repository.
Install the dependencies: npm install.
Create a .env file with the following variables:

NODE_ENV=production
PORT=3000

DB_HOST=localhost
DB_USER=user
DB_PASS=pwd
DB_PORT=3306

DB_NAME=mydatabase_test

    Start the server: npm start.

Features

    Basic routing with Express.js
    MySQL integration with Sequelize
    API endpoints for basic CRUD operations
